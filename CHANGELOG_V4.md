# VEKTOR BETA V4

## Вид ответа как в Алисе
- Живой блок «Думаю»: шаги (читаю запрос → смотрю в памяти → выбираю бесплатную модель) с точками, линией и плашками-источниками. После ответа сворачивается в строку «Ответ в режиме «…» · N с ›», по нажатию раскрывается.
- Строка ввода: `+` (файл, проект, голос, экспорт), «Режим: …», микрофон-диктовка, отправка/стоп. Эмодзи заменены единым набором значков.
- Кнопка «Стоп» прерывает запрос; «Ещё раз» повторяет последний ответ.

## Генератор проектов (замена Autopilot в интерфейсе)
- План → каждый файл отдельным запросом (до ~7,8 тыс. токенов) → дописывание, если файл не уместился (маркер `<<<END>>>`) → расширение слишком коротких файлов → проверка JS/JSON/HTML с автоисправлением → ZIP.
- Размеры: малый ~20 КБ, средний ~40 КБ, большой 50–70 КБ. Карточка проекта: список файлов, «Скачать ZIP», «Запустить» (предпросмотр в изолированной рамке).
- В чате Code запросы вида «создай проект/игру/сайт…» запускают сборку сами; также «+ → Создать проект».
- Воркер: режим `vk_big` — для больших файлов используются только сильные модели (без маленькой Cloudflare-модели).

## Новые удобства
- Экспорт чата в .md, запуск HTML-блоков из ответа («Запустить»), поиск и пометки чатов, диагностика (5 касаний по названию в шторке).

## Голосовой помощник
- Бесплатный нейроголос Microsoft Edge через ваш Worker (`POST /tts`, Дмитрий ♂ / Светлана ♀), запасные: Google (быстрый тест без Worker), Piper (офлайн), голос устройства. При сбое включается следующий вариант автоматически.
- Распознавание: речь браузера → запись + Whisper (`/stt`, привязка Workers AI `AI`).

## Ограничения
- Edge TTS — неофициальный протокол: проверена только логика (на подставном сервере), живой доступ из Cloudflare нужно проверить после деплоя; Microsoft может изменить условия.
- Проект на 50–70 КБ — это 10–15 запросов к бесплатным моделям: дневные лимиты расходуются быстрее.
- Python-Autopilot и веб-поиск (V3) остаются в движке, но в интерфейсе сборку ведёт новый генератор.
