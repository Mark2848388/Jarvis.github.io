# VEKTOR 5.0 — Hybrid Intelligence System

## Что включено в эту сборку

- **Python AI Engine + C++ core**: память SQLite, инструменты, плагины, рабочая область с подтверждением изменений и откатом.
- **Multi-AI Router FREE_ONLY**: бесплатный allowlist моделей, переключение между Groq / OpenRouter / Gemini / Cloudflare, локальный учёт вызовов и fallback. Платные модели отклоняются до отправки запроса.
- **Markdown UI**: заголовки `#`, выделение `*`, таблицы, списки, цитаты, ссылки и блоки кода отображаются как форматирование; специальные символы в коде сохраняются.
- **Время и статус**: под каждым ответом показываются фактическая длительность запроса, действие и провайдер.
- **VKTR Code**: отдельный профиль для качественного, безопасного и тестируемого кода.

## Бесплатный режим — важное ограничение

FREE_ONLY блокирует неизвестные и платные модели, но ни один сторонний API не гарантированно бесплатен навсегда. Бесплатные квоты меняются по регионам, аккаунтам и времени. Перед добавлением/обновлением модели проверяйте официальный тариф. Не добавляйте платёжные данные, если хотите сохранить строго бесплатный режим. Когда все квоты закончатся, Вектор сообщит об этом — платный резерв не используется.

## Запуск локально

Требуются Python 3.10+ и (необязательно) g++ для C++ ускорения.

```bash
cd vektor5
python3 server.py
```

Откройте `http://localhost:8080`. Без g++ используется Python fallback для C++ функций.

## Настройка бесплатных провайдеров

1. Скопируйте `FREE_ONLY.env.example` в `.env` или задайте переменные окружения в хостинге.
2. Добавьте API keys только в Secrets/переменные окружения сервера. Не вставляйте их в `ui/config.js`, HTML или Git.
3. Доступные настройки: `GROQ_API_KEY`, `OPENROUTER_API_KEY`, `GEMINI_API_KEY`; для прямого Cloudflare Workers AI нужны `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN`.
4. Либо настройте свой Cloudflare Worker через `GROQ_KEYS`, `OPENROUTER_KEY`, `GEMINI_API_KEY` и (опционально) binding `AI`. Его публичный URL находится в `ui/config.js`.
5. Worker проверяет только allowlist моделей и ограничивает трафик до 60 запросов/час/IP через KV `RL`.

## Router и квоты

В меню чата откройте **Multi-AI Router** → «Обновить статус». Локальная база `data/provider_usage.db` считает вызовы/ошибки по UTC-дню. Это локальная оценка, а не точное отображение квоты провайдера.

## ZIP

Архив содержит исходный код и настройки, но не содержит секретных API-ключей, пользовательской памяти или локальных данных.

## Дополнительные функции интерфейса

- 🎙 Голосовой ввод через Web Speech API (в браузерах с поддержкой SpeechRecognition; чаще всего Chrome/Android).
- Озвучивание ответа через системный SpeechSynthesis и доступные голоса устройства. Качество голоса зависит от установленных голосовых пакетов Android/браузера.
- Прикрепление файлов любого типа. Текстовые файлы и исходный код читаются браузером и передаются модели в сообщении. Для PDF/DOCX/XLSX и других бинарных форматов в этой сборке пока передаются имя, MIME-тип и размер; извлечение их содержимого требует отдельных парсеров.
- Кнопка ZIP извлекает fenced code blocks из последнего ответа и собирает ZIP прямо в браузере без сторонней библиотеки. Это сборка фрагментов кода, не полноценная компиляция или тестирование проекта.
